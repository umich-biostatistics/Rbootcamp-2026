# Codebook: `bootcamp_health.csv`

This is a simulated teaching dataset. It contains no real patient or participant records.

| Variable | Description |
|---|---|
| `participant_id` | Simulated participant identifier. |
| `visit_date` | Simulated visit date in 2026. |
| `cohort` | Screening or follow-up cohort indicator. |
| `age` | Age in years. |
| `sex` | Self-reported sex/gender category for teaching. |
| `race_ethnicity` | Broad race/ethnicity category for teaching. |
| `bmi` | Body mass index. Some values are missing. |
| `systolic_bp` | Simulated systolic blood pressure. Some values are missing. |
| `diastolic_bp` | Simulated diastolic blood pressure. |
| `total_cholesterol` | Simulated total cholesterol. |
| `smoking_status` | Never, former, or current smoker. Some values are missing. |
| `diabetes` | Simulated yes/no diabetes indicator. |
| `physical_activity_min_week` | Simulated minutes of physical activity per week. Some values are missing. |
| `sleep_hours` | Simulated average hours of sleep. Includes a few values worth checking. |
