# AI prompt cards for R learners

Use AI to learn faster, not to skip understanding.

## Explain code

> I am learning R. Explain this code line by line in beginner language. Focus on the purpose of each function and the shape of the data after each step.

## Debug code

> This R code gives the error below. Explain what the error means, identify the most likely failing line, and suggest two inspection commands I should run before changing the code.

## Check a plot

> I am trying to make a ggplot that shows [purpose]. Here are my column names and my code. Suggest the smallest change needed. Do not invent new column names.

## Refactor working code

> This repeated R code already works. Help me turn it into a small function. Explain the arguments, the return value, and one test case.

## Protect data

Do not paste protected health information, credentials, private institutional data, or unpublished sensitive research data into third-party AI tools. For U-M data, use U-M-approved tools and follow course and university guidance.
